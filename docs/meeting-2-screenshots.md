# מפגש 2 - רשימת צילומי מסך לצילום

מפגש 2 עתיר ממשקים (GitHub, Codespaces, טרמינל, GitHub Pages, Moodle), ולכן
צילומי מסך עוזרים למשתתפת לדעת "איך זה אמור להיראות" בכל שלב. כרגע אין ביחידות
אף תמונה.

שם קובץ מוצע: `img/m2/<מזהה>.png`. אחרי הצילום אפשר להטמיע בבלוק `image`
ביחידה המתאימה. מומלץ לסמן בחץ/מסגרת את הכפתור הרלוונטי.

מקרא: 🐙 GitHub · 💻 Codespaces/VS Code · ⌨️ טרמינל · 🎓 Moodle · 📱 האפליקציה

## הערות

- **עקביות:** כדאי לצלם את כל GitHub/Codespaces מאותו חשבון הדגמה ואותה שפה.
- **הטמעה הדרגתית:** לא חובה הכול בבת אחת - הצילומים הקריטיים ביותר הם 5–6
  (Codespaces, שהוא המקום הכי לא־מוכר), 14–15 (Pages), ו־18–20 (SCORM במודל).
- **מובייל:** צילומי 📱 (16, 11) יכולים להיות גם מהטלפון, להראות שהאתר עובד בכל מכשיר.
