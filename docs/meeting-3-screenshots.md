# מפגש 3 - רשימת צילומי מסך לצילום

רשימת צילומי המסך שצריך להכין למפגש 3 (Firebase). רובם מקונסולת Firebase
(`console.firebase.google.com`), ומעטים מהאפליקציה עצמה. מומלץ לצלם באנגלית
(שפת הקונסולה) ולסמן בחץ/מסגרת את הכפתור הרלוונטי.

שם קובץ מוצע: `img/m3/<מזהה>.png`. אחרי הצילום אפשר להטמיע בבלוק `image`
ביחידה המתאימה (`{ kind: "image", src: "img/m3/...", alt: "...", caption: "..." }`).

מקרא: 🖥️ קונסולת Firebase · 📱 האפליקציה שלנו

---

## הערות

- **אבטחה בצילומים:** ה־`firebaseConfig` אינו סוד אמיתי, אבל אל תצלמי מפתחות
  פרטיים / service account / סיסמאות. ההגנה היא בכללי האבטחה.
- **עקביות:** כדאי לצלם את כל הקונסולה עם אותו פרויקט הדגמה ואותה שפה.
- **אופציונלי:** אפשר להוסיף צילום של ה־**Rules Playground** (סימולטור הכללים)
  כהמחשה שההגנה עובדת, אם רוצים להעמיק ב־u6.
