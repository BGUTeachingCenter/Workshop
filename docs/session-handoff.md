## מה הושלם

### 1. שוויון מגדרי בכל המלל ✅
כל הטקסט עבר מלשון נקבה ל**לשון רבים** מכלילה (חשבי→חשבו, מתחילות→מתחילים,
מנחָה→מנחה, משתתפת→משתתף/ת). נבדק: אפס שאריות + בדיקה חיה.

### 2. מפגש 1 - סגור ✅
9 יחידות, מבנה שלם, נבדק חי (progressive disclosure, תצוגת משתתף/מנחה).

### 3. Firebase - חי ועובד ✅
האתר רץ מול Firebase אמיתי (`BACKEND="firebase"` ב-`app/config.js`), החליף את
ה-mock המקומי. התחברות אמיתית, נתונים משותפים בין מכשירים, ומנחה משותף - נבדק
ועובד (כניסת מנחה מציגה שקפים).
- **כניסה:** שם + אימייל + **סיסמת הסדנה** המשותפת (`WORKSHOP_PASSWORD` ב-config).
- **מי מנחה (אדמין):** נקבע לפי **רשימת אימיילים**, לא עוד לפי "+admin".
- פרויקט Firebase: `gen-lang-client-0866732986` (Firestore + Email/Password + Rules).

#### ➕ איך מוסיפים הרשאת מנחה למרצה
רשימת המנחים חיה ב**שני מקומות שחייבים להיות זהים**:
1. `app/config.js` → `ADMIN_EMAILS` (שולט ב-UI).
2. `firestore.rules` → הרשימה ב-`isAdmin()` (אוכף בצד השרת).

השלבים:
1. להוסיף את האימייל (אותיות קטנות) לשתי הרשימות.
2. commit + push.
3. בקונסולה: **Firestore → Rules → להדביק את הגרסה המעודכנת → Publish**
   (קובץ הכללים ברפו לא מתפרסם אוטומטית).
4. המרצה נכנס עם האימייל + סיסמת הסדנה → מנחה. אם כבר נכנס כמשתתף -
   התפקיד מתעדכן אוטומטית בכניסה הבאה (resolveUser ב-firebase.js).

מנחים נוכחיים: `inbaltsa@post.bgu.ac.il`, `motkep@bgu.ac.il`.

## איך רואים את האתר
אפליקציית HTML סטטית עם ES Modules - חייבים לשרת דרך http (לא file://):
```
git checkout main && git pull
python3 -m http.server 8000      # הפורט בדפדפן = הפורט כאן!
```
← `http://localhost:8000` + **רענון קשיח `Ctrl+Shift+R`** (ES Modules נתקעים ב-cache).
כניסה: שם + אימייל + סיסמת הסדנה. אימייל מרשימת המנחים = תצוגת מנחה עם שקפים.
