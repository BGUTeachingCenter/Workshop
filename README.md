# מהצורך לכלי

אב־טיפוס ראשוני לסביבת הלמידה של סדנת **Vibe Coding בהוראה**.

## הרצה מקומית

אין צורך בהתקנת תלויות. אפשר לפתוח את `index.html` ישירות בדפדפן, או להריץ שרת מקומי:

```bash
python3 -m http.server 8000
```

לאחר מכן פותחים את <http://localhost:8000>.

## מה כלול באב־הטיפוס

- ממשק עברי מלא בכיוון RTL.
- ארבע יחידות ראשונות של מפגש 1.
- מצבי תוכן נוכחי ונעול.
- שמירת תשובות והיחידה האחרונה בדפדפן.
- תצוגה מותאמת למסכים קטנים.

האב־טיפוס משתמש כרגע ב־HTML, CSS ו־JavaScript ללא backend. חיבור למערכת משתמשים ול־Firebase מתוכנן לאיטרציה נפרדת, לאחר אישור חוויית המשתמש.
