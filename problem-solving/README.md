# מיומנות פתרון בעיות — מיני-אתר לצוות

אתר של צוות עבודה בין-מוסדי בתכנית "מארג ידע" של קרן רוטשילד (לא מטעם היחידה). תיקייה עצמאית, **לא קשורה לסדנת הוייב קודינג** שבשאר ה-repo. מתפרסמת יחד עם ה-repo ב-GitHub Pages:
`https://bguteachingcenter.github.io/Workshop/problem-solving/`

- **ארבעה דפים:** `index.html` (מיפוי התהליך) · `theory.html` · `examples.html` · `template.html`. עיצוב משותף ב-`styles.css`, ותוכן + קוד משותפים ב-`app.js`: הרשימות `STAGES`, `MODELS`, `CONCEPTS`, `REFS`, `EXAMPLES` בראש הקובץ.
- **הערות הצוות:** כל כפתור ✎ פותח טופס Google עם שם הקטע ממולא מראש (`FORM_URL`, `FORM_SECTION`). התשובות אצל ענבל (Responses בטופס).
- **להוספת דוגמה:** אובייקט חדש ב-`EXAMPLES` לפי השדות של הדוגמאות הקיימות.
- **רעיון לשיעור (`idea.html`):** טופס קצר → רעיון אחד מ-Gemini (מסלול חינמי), דרך Google Apps Script שמחזיק את המפתח. קוד והוראות: `apps-script/`. הכתובת מודבקת ב-`app.js` (`IDEA_API`).
